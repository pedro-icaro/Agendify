O **Agendify** é um aplicativo mobile desenvolvido para otimizar a gestão de clientes e o controle financeiro de profissionais autônomos. De forma intuitiva e rápida, o usuário pode realizar agendamentos, acompanhar sua agenda de horários e ter uma visão clara do seu faturamento atual.

##  Funcionalidades

- **Gestão de Agendamentos:** Adicione novos clientes informando Nome, Data, Horário e Valor do serviço.
- **Controle de Faturamento:** Dashboard financeiro que calcula automaticamente o faturamento total com base nos serviços agendados.
- **Perfil Personalizável:** Área dedicada para o usuário personalizar o nome do seu perfil profissional, com reflexo imediato em todo o app.
- **Persistência de Dados:** Salvamento local e rápido garantindo que nenhum agendamento seja perdido ao fechar o aplicativo.
- **Interface Limpa e Moderna:** Design focado na experiência do usuário, utilizando paleta de cores elegantes (BlueGrey).

##  Tecnologias Utilizadas

- **[Flutter](https://flutter.dev/):** Framework principal para construção da interface.
- **[Dart](https://dart.dev/):** Linguagem de programação.
- **[Hive](https://pub.dev/packages/hive):** Banco de dados NoSQL local, ultrarrápido e leve para persistência de dados offline.
